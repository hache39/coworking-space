# Cozy Corner — Coworking Space 🏢

Landing page for a coworking space concept called **Cozy Corner**, built as a frontend practice project. Features a modern, responsive design with a clean navigation, hero section, and location highlights.

## 🖥️ Preview

> A responsive landing page for a coworking space with search functionality, hero section, and mobile-friendly navigation.

## ✨ Features

- Responsive navigation with hamburger menu for mobile
- Hero section with search bar
- Location and amenities highlight sections
- SASS architecture with abstracts, components, and layout separation
- Built with Vite for fast development

## 🛠️ Getting Started

### Prerequisites

- Node.js (v16+)
- npm

### Installation

```bash
# Clone the repo
git clone https://github.com/hache39/coworking-space.git

# Navigate to the project
cd coworking-space

# Install dependencies
npm install

# Start dev server
npm run dev
```
